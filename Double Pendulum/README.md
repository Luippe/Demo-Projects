Simulates the chaotic motion of a double pendulum by numerically integrating its
equations of motion. Tiny differences in the starting position lead to wildly
different paths — the classic demonstration of chaos.

## Controls

| Input | Action |
|-------|--------|
| `Space` | Start the simulation |
| `Esc` | Quit |
