# Demo Projects

Welcome to my collection of simulations, visualizations, and games built over the
past several years. Most are written in **Python** with
[pygame](https://www.pygame.org/); one (Boids) is written in **Java**.

**Quickest way to try one:** click the **⬇ Download** link under any demo in
[the gallery below](#the-demos), then double-click the file that downloads — no
install needed. If Windows shows a *"Windows protected your PC"* box, click
**More info → Run anyway**; that just means the file isn't code-signed. Press
**`Esc`** to quit any demo.

## Running from source

Works on any OS and needs **Python 3.9+**. Every demo folder has its own
`requirements.txt` and its own entry script (named in that demo's README):

```bash
cd "Conway Game of Life"
python -m venv .venv                 # optional but recommended
.venv\Scripts\Activate.ps1           # Windows PowerShell  (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
python main.py
```

Always launch a demo **from inside its own folder** — several of them load images,
fonts, or data tables by relative path. Two need extra care:

- **Audio Processing** needs speakers, plus a microphone for mic mode. It also
  needs `pyaudio` and `opencv-python`, the fiddliest packages here.
- **Boids** is Java, not Python — building it from source needs **JDK 17+**.

## Building the `.exe` files yourself

The Python demos are packaged with [PyInstaller](https://pyinstaller.org/) via
[`build_installers.py`](./build_installers.py); Boids uses Java's `jpackage`
(`BoidProject/Build-Boids.ps1`).

```bash
pip install pyinstaller
python build_installers.py            # builds into ./dist/
```

[`BUILD.md`](./BUILD.md) has the full build-and-release steps.
