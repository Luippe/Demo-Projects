Aim and launch a projectile with the mouse. Click and drag to set the direction
and power, then release to fire and watch the trajectory play out.

## Controls

| Input | Action |
|-------|--------|
| Click-drag, then release | Aim and launch the projectile |
| `Esc` | Quit |

## Run from source

```bash
pip install -r requirements.txt
python projectile_method.py
```

Opens fullscreen at 1920×1080.
