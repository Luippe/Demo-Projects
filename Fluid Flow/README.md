A real-time 2D fluid simulation. A steady source injects fluid into the grid;
move the mouse across the window to add more fluid and push it around, then watch
it diffuse and advect.

## Controls

| Input | Action |
|-------|--------|
| Move / drag the mouse | Add fluid and velocity |
| `Esc` or close the window | Quit |

## Run from source

```bash
pip install -r requirements.txt
python Fluid_Flow.py
```

Opens in a 300×300 window.
